# 🎓 EduPortal - School & Institute Management System

EduPortal is a modern full-stack School & Institute Management System built with the MERN Stack. It provides a complete solution for managing students, faculty, admissions, fees, notices, achievements, gallery, testimonials, downloads, and administrative operations through a powerful admin dashboard.

## 🚀 Live Demo

Frontend: https://eduportal-mern.vercel.app

Backend API: https://eduportal-backend-m5t1.onrender.com

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/vickey-singh/eduportal-mern.git
cd eduportal-mern
```

### Backend Setup

```bash
cd server
npm install
```

Create `.env`

```env
MONGO_URI=your_mongodb_connection_string
```

Start Backend

```bash
npm run dev
```

### Frontend Setup

```bash
cd client
npm install
npm run dev
```
